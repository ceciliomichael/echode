# Markdown Viewer

A standalone VS Code Extension extracted from EchoDE providing a custom Markdown previewer with:
- Live, real-time preview updates as you type
- Direct Mermaid diagram rendering with custom themes
- Syntax highlighted code blocks with language icons and copy support
- Interactive anchor links and smooth scrolling
- Clean VS Code theme integration

## Features

- **Keyboard Shortcut**: Press `Ctrl+Shift+V` (`Cmd+Shift+V` on Mac) while focusing a markdown file to launch the preview.
- **Command Palette**: Run `Open Markdown Preview` (`markdown-viewer.openPreview`).
